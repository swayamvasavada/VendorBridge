# VendorBridge

VendorBridge is a Procurement & Vendor Management ERP system that helps organizations manage vendors, RFQs, quotations, approvals, purchase orders, and invoices in one place.

## Features

- User Authentication & Role-Based Access
- Vendor Management
- RFQ Creation & Management
- Vendor Quotation Submission
- Quotation Comparison
- Approval Workflow
- Purchase Order Generation
- Invoice Generation
- Activity Logs & Notifications
- Reports & Analytics

## User Roles

- Admin
- Procurement Officer
- Vendor
- Manager / Approver

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- SpringBoot
- Java

### Database
- SQL Server

## Installation

```bash
git clone <repository-url>
cd vendorbridge
npm install
```

## Run Project

```bash
npm run dev
```
